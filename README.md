# windows-toolbox

Small, single-purpose PowerShell tools for Windows 11, kept in one place so they are not lost and
so each one can be read in a few minutes before it is run as administrator.

| Tool | What it does |
| --- | --- |
| [dns-adblock](dns-adblock/) | System-wide ad and tracker blocking through AdGuard DNS over HTTPS, with no driver, proxy, service or certificate. |
